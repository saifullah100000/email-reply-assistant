Email Reply Assistant:
A full-stack application that generates professional email replies using AI.

Tech Stack:
React (Vite)
NestJS
OpenAI API
Axios

Features:
1 Generate AI-powered email replies
2 Select reply tone
3 Copy generated reply
4 Input validation
5 Responsive UI

AI Integration:
This project uses Google's Gemini API
for generating email replies.

The AI service is isolated inside the backend,
allowing the provider to be changed easily.
